🧪 Try to break it

Press the button: the robot tries to overwrite a real note in the table, and the edit screen tries to fake a score. Every attempt is wrapped in a transaction that is forced to roll back, so pressing this is always safe.

🧾 Fingerprint of Vikram's columns, before and after every run

An MD5 hash of all his columns (name, firm, thesis, status, last contact, contact history, notes) is taken when a run starts and again when it ends. If they match, nothing of his changed.
